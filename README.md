# FoodFlow — мобильное приложение для питания

Цель: PWA для iPhone/Android, которое автоматизирует недельное меню, подбор продуктов, список покупок и контроль питания. Сначала local-first MVP, затем интеграции.

## MVP
- Ежедневные ориентиры по калориям и белку, ручная настройка.
- Меню на 7 дней, замены блюд с учётом ограничений и времени готовки.
- Автоматическая агрегация списка покупок с количеством и примерным бюджетом.
- Учёт приёмов пищи, локальное хранение и экспорт/импорт данных.
- Поиск продуктов и настраиваемые цены.
- PWA: мобильная адаптация, возможность установки на главный экран, офлайн после первой загрузки.
- Русский интерфейс, понятный без технической подготовки.

## Правила
1. Исполнитель — Codex; ChatGPT — технический менеджер и QA.
2. Изменения только через feature branch + Pull Request с тестами.
3. Не считать задачу готовой без проверки функциональности и мобильного UX.
4. Никаких API-ключей в браузере. Никаких медицинских или точных коммерческих обещаний.
5. Пользовательские данные не коммитить в публичный репозиторий.

Актуальное техническое задание находится в Issues. Для публикации можно использовать GitHub Pages: Settings → Pages → Deploy from a branch → main / (root) после появления готовых файлов.
