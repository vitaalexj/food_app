# FoodFlow — мобильное приложение для питания

**FoodFlow** — первая версия PWA для iPhone и Android: меню на неделю, учёт питания, подбор продуктов и автоматический список покупок. Интерфейс на русском, без регистрации.

## Установка на телефон
1. В GitHub откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветка **main**, папка **/(root)**, **Save**.
3. После появления адреса Pages откройте **https://vitaalexj.github.io/food_app/** (публикация зависит от настройки Pages).
4. iPhone: Safari → **Поделиться → На экран «Домой»**. Android: Chrome → меню → **Установить приложение** / **Добавить на главный экран**.

После первой загрузки основные страницы приложения могут быть доступны офлайн благодаря Service Worker. Интернет потребуется для первоначальной установки и обновлений.

## Функции MVP
- Меню на ближайшие 7 дней: завтрак, обед, ужин, перекус.
- Замена блюда с учётом времени готовки и заданных исключений.
- Учёт фактически съеденного и приблизительных ккал/белка.
- Автоматически агрегируемый список покупок по порциям и примерная стоимость, чек-лист.
- Каталог продуктов, поиск, изменение ориентировочной цены за 100 г.
- Профиль: вес, цель, калории, белок, бюджет и ограничения.
- Резервная копия данных JSON (экспорт и импорт).

**Профиль содержит нейтральные демонстрационные значения.** Свои цифры заполняйте в разделе «Профиль». Данные хранятся только в браузере и не синхронизируются между устройствами. Для сохранности скачивайте резервные копии.

## Разработка и проверка
- Codex выполняет задачи в отдельной ветке и передаёт Pull Request на ревью.
- ChatGPT формулирует критерии приёмки и проверяет изменения, тесты и поведение.
- Первая задача: [MVP FoodFlow](https://github.com/vitaalexj/food_app/issues/1).
- Без зависимостей: HTML + CSS + JavaScript.
- Запуск локально: `python -m http.server 8000` → http://localhost:8000 .
- Проверка кода: `node --check app.js`, `node tests/core.test.cjs`.
- Автоматическая проверка в GitHub Actions на push/PR.

## Ограничения
- Это **правила и каталог рецептов**, а не реальная ИИ-генерация, хотя будущий ИИ-помощник планируется.
- Калории, БЖУ, продукты и цены приблизительны, не являются медицинским советом или актуальными ценами магазинов.
- Аллергенные фильтры не заменяют ручную проверку состава продуктов и перекрёстных контактов.
- Нет оплаты, онлайн-заказов и автоматического получения цен супермаркетов.
